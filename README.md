 🔍 DeepTrace
Multimodal Deepfake Detection and Media Authenticity Verification System

🚀 [Try the Live Demo](https://deeptrace-2t6sbwljnlb7brgub6wfkn.streamlit.app/)**

DeepTrace is a web-based AI system that analyzes images and videos
for signals commonly associated with AI-generated or manipulated media.

✨ Features

- 🖼️ Image deepfake detection
- 🎥 Video analysis
- 🤖 AI-based visual analysis
- 📊 Section-by-section video results
- 🟢 Likely Real / 🔴 Likely AI-Generated results
- 📄 Exportable analysis results

 ⚠️ Disclaimer

Results are screening signals, not proof of authenticity.
